# Kingdom Rush 修改器

单文件工具 `KingdomRush修改器.exe`（≈36 MB，免安装），注入 Lua 脚本读写游戏内存数值。
不改游戏文件、不联网、退出游戏即还原。界面：新粗野主义（米白底 + 黑粗边 + 硬阴影）。

适用：Steam 版 `kr1-desktop-6.4.46`（appid 246420），Windows 10/11 x64。

## 使用

1. 双击 exe，UAC 点「是」（Steam 启动的游戏是提权进程，必须管理员）
2. 点「启动 / 连接游戏」（游戏没开则经 Steam 启动后自动注入）
3. 顶部「桥接 已连接」出现黄点即生效，勾选功能即可

## 功能

界面两块：**01 修改设置**（分页：全局设置 / 防御塔 / 英雄与友军）+ **02 运行日志**。

| 分页 | 功能 |
|---|---|
| 全局设置 | 游戏速度（1x–8x / 自定义）→ 锁定金币 / 杀敌金币倍率 / 每秒自动增加金币 → 锁定基地生命 / 自动下一波 |
| 防御塔 | 22 种塔按四系聚合 4 行（弓兵/法师/火炮/兵营），每行「攻速 / 伤害 / 范围」勾选 + 倍数；兵营行为「士兵数量 / 范围」 |
| 英雄与友军 | 每帧回满血 / 英雄瞬间满级 / 技能援军无冷却 / 援军总数（2–10）/ 援军持续时间（5–300 秒） |

- 倍数按「系」生效，覆盖该系全部等级与进阶；1 = 不变，取消勾选即还原
- 攻速有上限（开火动画时长），悬停「攻速」表头看各系上限倍数
- 范围会同步放大：塔射程、每种攻击模式自带射程（如大贝莎的导弹/炸弹/集束）、弹道跟踪距离
- 「恢复全部」一键关闭所有修改

## 源码

`src/`：
- `trainer.py` — PySide6 界面 + 注入器（ctypes 调 Win32 注入）
- `krbridge.c` / `krbridge.dll` — 注入 DLL，IAT Hook `lua51.dll` 后执行 Lua 载荷
- `payload.lua` — 游戏内脚本，每 0.1s 读 `state.txt` 应用修改，写 `status.txt` / `towers.txt`

打包：推 tag 后由 GitHub Actions 自动完成（`.github/workflows/build.yml`），产物同时上传为构建产物和草稿 Release 资产。
本地手工打包（调试用）：
```
cd src
pip install -r requirements.txt
python -m PyInstaller --noconfirm --clean --onefile --noconsole --uac-admin --name KingdomRushTrainer --icon app.ico --add-data "krbridge.dll;." --add-data "payload.lua;." trainer.py
```
打包后自检：`dist\KingdomRushTrainer.exe --selftest`（退出码 0 为通过，报告写入 `%TEMP%\KR_Trainer_selftest.txt`）
重编 DLL（需 zig）：`zig build-lib krbridge.c -dynamic -O ReleaseSmall -target x86_64-windows-gnu -lc`
