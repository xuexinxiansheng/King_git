# Kingdom Rush 修改器 · 使用指南

适用 Steam 版 `kr1-desktop-6.4.46` · 单文件免安装 · 需管理员权限（Steam 启动的游戏是提权进程）

## 上手

1. 双击 `KingdomRush修改器.exe`，UAC 点「是」
2. 点「启动 / 连接游戏」：游戏没开 → 经 Steam 启动并注入；已开 → 直接连接
3. 看到「桥接 已连接」黄点即生效，勾选功能即可

先开游戏或先开修改器都行。

## 界面

| 区域 | 说明 |
|---|---|
| 标题栏 | 拖动移动窗口；右上 ─ □ ✕ 最小化/最大化/关闭 |
| 状态区 | 游戏路径 + 进程/桥接状态点，实时显示关卡/波次/金币/生命 |
| 01 修改设置 | 三个分页左右切换：`全局设置` / `防御塔` / `英雄与友军` |
| 02 运行日志 | 常驻下方，记录注入与每次改动 |

## 功能

### 全局设置

| 功能 | 用法 | 说明 |
|---|---|---|
| 游戏速度 | 1x–8x 或手填 0.1–20 | 移动/攻击/弹道/出兵整体加速 |
| 锁定金币 | 勾选 + 数值（默认 9999） | 每帧写回，买塔升级不掉钱 |
| 杀敌金币倍率 | 填倍数或点 2x–10x | 额外发放「赏金 × 倍数」；填 0 关闭 |
| 每秒自动增加金币 | 勾选 + 数值（默认 100） | 每秒产出，可与锁定同时开 |
| 锁定基地生命 | 勾选 + 数值（默认 20） | 敌人漏过也不掉 |
| 自动下一波 | 勾选 | 每波结束立即开下一波 |
| 恢复全部 | 顶部按钮 | 关闭所有修改、速度回 1x |

### 防御塔

22 种塔按**四大系**聚合（升级与进阶归入本系）。前三系每行三列 = 攻速 / 伤害 / 范围，兵营系是士兵数量 + 范围：

| 塔系（自上而下） | 包含 |
|---|---|
| 弓兵系（5 种） | 弓兵塔 → 射手塔 → 神射手 → 游侠匿所 / 火枪手要塞 |
| 法师系（5 种） | 法师塔 → 术士塔 → 巫师塔 → 魔法师 / 奥术防御塔 |
| 火炮系（5 种） | 矮人炮塔 → 进阶火炮 → 矮人榴弹炮 → 特拉斯x104 / 500mm大贝莎 |
| 兵营系（6 种） | 民兵兵营 → 步兵兵营 → 骑士兵营 → 神圣秩序 / 蛮族大殿 / 精灵塔 |

- 倍数作用于该系全部等级与进阶；1 = 不变，取消勾选即还原
- **攻速有上限**：实际间隔 = max(冷却, 开火动画)。上限倍数：弓兵≈4.8x（神射手/游侠≈3x）、法师≈5.6x（魔法师≈4.1x、奥术≈3x）、火炮≈7.5x（大贝莎≈4.8x、**特斯拉≈1.4x**）、火枪手≈7.5x
- **范围**会同步放大：塔射程、每种攻击模式自带射程（大贝莎的导弹 / 炸弹 / 集束炸弹各有自己的射程）、弹道跟踪距离，远目标也能打中
- 兵营系不攻击，前两列合并为**士兵数量**（1–20，默认取该系各级真实值）：兵营按这个数量自动补人。
  数量写进模板，所以**升级时全部士兵一起升级**（不会出现三个升级、其余从门里重出）；新建的兵营则是一个个开门出人
- 兵营系的「范围」= 驻扎半径

### 英雄与友军

| 功能 | 用法 | 说明 |
|---|---|---|
| 每帧回满血 | 勾选 | 英雄/援军/兵营士兵血量满格 |
| 英雄升级到满级 | 勾选 | **立刻满级**，血量/护甲/攻击/回血同步到最高档 |
| 技能与援军无冷却 | 勾选 | 火雨与援军冷却清零；取消勾选立刻恢复原冷却 |
| 援军总数 | 勾选 + 数量（默认 4，2–10） | 呼叫一次后的士兵总数（基础 2 个），上限 10 个；连续连点每次都补足 |
| 援军持续时间 | 勾选 + 秒数（默认 60，5–300） | 在场停留时间；游戏默认 20 秒 |

## 常见问题

- **双击没反应 / 一闪就没了**：杀软拦截，加入信任。工具只读游戏进程、写 `%LOCALAPPDATA%\KR_Trainer`。
- **注入失败 错误码 5**：权限不够，右键 exe →「以管理员身份运行」。
- **桥接一直等待**：进一次关卡或切一次界面即可。
- **更新修改器后功能没变化**：游戏进程里跑的还是旧脚本。新版本开机会自动让它热重载（`status.txt` 的 `v=` 与 exe 版本一致即成功）；
  若自动同步失败，退出游戏重开一次即可。
- **塔表显示「内置数据 · 22 种」**：正常，用的是内置参数；连上游戏会自动同步真实参数。
- **兵营系没有攻速/伤害**：兵营靠士兵作战，本身不攻击，所以改成「士兵数量」。
- **卖塔重建还有没有效**：有。倍数按系下发，每 0.1 秒重新应用到该系所有塔。
- **改了兵营士兵数量没立刻变多**：新兵只能从兵营门里出来，要等几秒；调小不会赶走已在场上的士兵（升级时才按新数量取舍）。
- **改成 8/20 人会不会冲突**：不会。已建的兵营补到新数量，之后升级会把这批人整批带过去；只有「新加的人」需要从门里走出来。
- **游戏更新后不能用**：按 6.4.46 字段实现，大版本更新可能改字段名。

## 安全与还原

- 只改内存，退出游戏即还原，不破坏存档
- 唯一环境改动：存档 `settings.lua` 写入 `skip_settings_dialog = true`（免弹分辨率窗），删掉即恢复
- 卸载：删除 exe 与 `%LOCALAPPDATA%\KR_Trainer`

> 单人游戏专用。
