## 硬阴影做法（重要）

Qt QSS **不支持 `box-shadow`**，**也不要用 `QGraphicsDropShadowEffect`**——它把控件渲染进离屏 pixmap 再合成，实测导致**文字重影**。

- 卡片 `NeoCard` / 窗口按钮 `WinButton`：`paintEvent` 里先画右下偏移的实心圆角块当阴影，再画主体（主体路径内缩 `BORDER/2 + 0.5`，否则描边被裁掉一半、边缘发虚）。
- 普通按钮：外面包一层 `ShadowWrap`（同样自绘偏移块），**不要用「右下边框加粗」冒充阴影**——圆角处 5px 与 3px 边接缝会错位。
- `ShadowWrap` 的子控件不在布局中，必须 `child.show()`；容器不要设 `background:transparent`（QSS 级联会把按钮背景清成透明，阴影从底下透出变黑块）。
- 中文文本关闭字距（`has_cjk` 检测），否则松散发虚。

## 其他

- 分页按钮 `QPushButton#tab[on="true"]` 黄底表示当前页
- 塔表格表头与数据行共用列宽常量 `TW_COL_W`，否则列错位
- 按钮/输入框边框统一 3px `#111111`，圆角 7–9px
- 输入框禁用态灰底灰字；`QLineEdit#tw` 为塔倍数框、`#val` 为功能数值框
